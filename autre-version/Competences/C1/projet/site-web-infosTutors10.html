InfosTutors

Ce projet est un site web pour les futurs étudiants en première. Il est conçu pour que les étudiants puisse travailler correctement sur leur année en BUT avec des cours qui sont fournis, des TP personnaliser pars les Tuteurs et des petits quizs.

Cours

Les cours sont regrouper par matière, de plus c'est des cours repris par les profs

TP

Les TP sont totalement personnaliser par les Tuteurs sur des thèmes que sa sois dans des jeux, film ou autre pour, mettre plus de dans le côté étudiants pour éviter aux étudiants de stesser.

Quiz

Les quizs sont un moyenne pour apprendre mieux du vocabulaire et facilité aux étudiants de se perdre dans les les révisions.
