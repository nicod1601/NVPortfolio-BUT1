TaskMaster

Application mobile de gestion de tâches et de productivité

Java Android SQLite API REST UX/UI
📱
Période Septembre 2024 - Décembre 2024
Contexte Projet tuteuré BUT Informatique - 3ème année
Équipe 4 développeurs, travail collaboratif avec Git
Mon rôle Chef de projet et développeur principal Android
Note obtenue 18/20

TaskMaster est une application mobile Android conçue pour aider les utilisateurs à organiser efficacement leurs tâches quotidiennes, projets et objectifs. Elle se distingue par son interface intuitive, ses fonctionnalités avancées de planification et ses outils d'analyse de productivité.

Ce projet a été réalisé dans le cadre de ma formation en BUT Informatique et démontre ma maîtrise des compétences en développement d'applications mobiles, en conception d'interface utilisateur et en gestion de données locales et distantes.

Architecture de l'application

TaskMaster est construit selon le pattern d'architecture MVVM (Model-View-ViewModel), ce qui permet une séparation claire des responsabilités et facilite la maintenance et l'évolution de l'application.

Structure du projet
com.example.taskmaster/
  ├─ data/
  │   ├─ model/       # Entités et modèles de données
  │   ├─ repository/  # Repositories pour accès aux données
  │   ├─ local/       # Sources de données locales (Room)
  │   └─ remote/      # Sources de données distantes (API)
  ├─ ui/
  │   ├─ tasks/       # Écrans et composants liés aux tâches
  │   ├─ projects/    # Écrans et composants liés aux projets
  │   ├─ analytics/   # Écrans d'analyse et statistiques
  │   └─ settings/    # Écrans de paramètres
  ├─ viewmodel/       # ViewModels pour chaque écran
  └─ util/            # Classes utilitaires et extensions

L'application utilise Jetpack Components pour une architecture moderne et robuste :

  • LiveData pour les données observables
  • ViewModel pour la logique de présentation
  • Room pour la persistance des données
  • DataBinding pour lier les vues au modèle
  • Navigation Component pour la gestion de la navigation

Gestion des données

La base de données locale utilise SQLite via la bibliothèque Room pour un accès typesafe aux données et une gestion efficace des migrations.

Entité Task
@Entity(tableName = "tasks")
public class Task {
    @PrimaryKey(autoGenerate = true)
    private long id;
    
    @NonNull
    private String title;
    
    private String description;
    
    @ColumnInfo(name = "due_date")
    private Date dueDate;
    
    private int priority;
    
    @ColumnInfo(name = "is_completed")
    private boolean isCompleted;
    
    @ColumnInfo(name = "project_id")
    private long projectId;
    
    // Getters, setters, constructors...
}

La synchronisation avec le serveur est gérée par un service en arrière-plan qui utilise WorkManager pour garantir la persistance des opérations même en cas de connectivité intermittente ou de redémarrage de l'appareil.

Interface utilisateur

L'interface utilisateur est construite selon les principes du Material Design, avec une attention particulière à l'expérience utilisateur et à l'accessibilité.

  • Utilisation de composants Material Design
  • Animations fluides pour améliorer l'expérience utilisateur
  • Support du mode sombre
  • Layouts responsive pour différentes tailles d'écran
  • Accessibilité WCAG AA pour tous les écrans principaux

Les transitions entre les écrans utilisent les Motion Layout et Shared Element Transitions pour créer une expérience utilisateur cohérente et agréable.

API et services

L'application communique avec un backend RESTful développé en Spring Boot, utilisant Retrofit pour les appels réseau et Gson pour la sérialisation JSON.

Interface API
public interface TaskApiService {
    @GET("tasks")
    Call<List<Task>> getTasks();
    
    @GET("tasks/{id}")
    Call<Task> getTaskById(@Path("id") long taskId);
    
    @POST("tasks")
    Call<Task> createTask(@Body Task task);
    
    @PUT("tasks/{id}")
    Call<Task> updateTask(@Path("id") long taskId, @Body Task task);
    
    @DELETE("tasks/{id}")
    Call<Void> deleteTask(@Path("id") long taskId);
    
    // Autres méthodes pour projets, utilisateurs, etc.
}

L'authentification utilise JWT (JSON Web Tokens) pour sécuriser les communications entre l'application mobile et le serveur, avec un stockage sécurisé des tokens via EncryptedSharedPreferences.
